# FUCKTORY · Tour 3D

Modello 3D in fotogrammetria dello spazio FUCKTORY (Via Bernardino Corio 8, Milano), ottimizzato per il web.

| File | Cosa contiene |
| --- | --- |
| `fucktory-3d.glb` | Modello (soffitto rimosso, texture WebP 2048 px, compressione meshopt), 11,7 MB |
| `poster.webp` | Immagine mostrata mentre il modello carica |
| `embed-odoo.html` | Codice da incollare in un blocco "Embed Code" di Odoo |

I file sono serviti da jsDelivr, fissati a un commit:

```
https://cdn.jsdelivr.net/gh/Cloud1o/general@5e5e198864965667fd6198165369e0547915ff0c/fucktory-3d/fucktory-3d.glb
```

Per aggiornare il modello: sostituisci il file, fai commit e cambia l'hash del commit negli URL di `embed-odoo.html`.
